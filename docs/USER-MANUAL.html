1. Getting Started

System Requirements

  • Web browser: Chrome, Firefox, Safari, or Edge (latest versions)
  • Internet connection
  • Screen resolution: 1280×720 or higher recommended

Accessing the System

  1. Open your web browser and navigate to the application URL
  2. Enter your email and password on the login page
  3. If you have Two-Factor Authentication enabled, enter the 6-digit code from your authenticator app
  4. Click Sign In
Note: After 5 failed login attempts, your account will be temporarily locked for 15 minutes. After 3 failed attempts, a security check (math question) will appear.

Logging Out

Click your name in the top-right corner and select Log Out. The system will automatically log you out after 30 minutes of inactivity, with a 5-minute warning.

3. Dashboard

After login, you land on the dashboard. It shows role-specific statistics:

  • Cashier: Today's sales count, total revenue, recent transactions, quick access to POS
  • Inventory Manager: Product counts, low stock alerts, stock in/out chart, quick actions
  • Store Manager: Sales revenue chart, transaction overview, report shortcuts
  • Admin: User stats, system overview, recent audit log activity

4. Inventory Management

Accessible to: Inventory Manager, Admin

Viewing Products

  1. Click Products in the navigation bar
  2. Use the filter bar to search by name/SKU, filter by category, supplier, or status
  3. Click View on any product to see details, variants, and stock history

Adding a Product

  1. Click Add Product
  2. Fill in product name, SKU, category, supplier, price, cost, quantity, and low stock threshold
  3. Optionally upload a product image
  4. Click Create Product

Product Variants

On the product detail page, scroll to the Add Variant form. Variants allow different versions of the same product (e.g., different sizes, colors). Each variant has its own SKU, stock quantity, and price modifier. The POS system shows variants as selectable options during checkout.

Importing Products

  1. Click Import on the Products page
  2. Upload a CSV or Excel file with columns: sku, name, category, supplier, price, cost, quantity, low_stock_threshold, unit
  3. Duplicate SKUs will be updated instead of creating duplicates
  4. Errors for specific rows are shown after import

Exporting Products

Click Excel, Export CSV, or Export PDF to download product data in your preferred format.

5. Stock Transactions

Accessible to: Inventory Manager, Admin

  1. Click Stock in the navigation bar
  2. View all stock movements with filters by product, type, and date range
  3. Click Add Stock Movement to record:
  • Stock In: Receiving new inventory — increases product quantity
  • Stock Out: Manual removal — decreases product quantity (cannot exceed available)
  • Adjustment: Set the exact quantity (for inventory corrections)

Each transaction records: quantity before, quantity after, reference number, user, and notes.

6. Point of Sale (POS)

Accessible to: Cashier, Admin

Making a Sale

  1. Click Point of Sale in the navigation bar
  2. Search for products by name or SKU in the search bar
  3. For products with variants, select the specific variant from the dropdown
  4. Click Add to add items to the cart
  5. Adjust quantities in the cart if needed
  6. Select payment method (Cash, Card, Check, Bank Transfer)
  7. For cash payments, enter the amount tendered — change is calculated automatically
  8. Apply discount if applicable (percentage or fixed amount)
  9. Click Complete Sale to finalize

Receipt

After checkout, a receipt is displayed. You can:

  • Download PDF: Professional A4 receipt with all transaction details
  • Print: Direct print via browser
  • New Sale: Start another transaction immediately

My Sales

Cashiers can view their own sales history by clicking My Sales.

8. Admin Panel

Accessible to: Admin only

User Management

  1. Click Admin → Users
  2. View all users with search/filter by name, email, role, status
  3. Create new users with role assignment
  4. Toggle user status (Active/Inactive)
  5. Edit user details or delete users

Audit Logs

  1. Click Admin → Audit Logs
  2. View all system activity: logins, logouts, CRUD operations, password resets, MFA changes, backups
  3. Filter by action type, model type, date range, or keyword search
  4. Export to CSV for external analysis

9. Store Settings

Accessible to: Store Manager, Admin

  1. Click your name → Settings (or from Transactions page)
  2. Configure: Store name, address, tax rate, tax label, currency symbol, receipt footer
  3. Configure SMTP email settings for system notifications
  4. Click Save Settings
Backup: At the bottom of the Settings page, click Backup Now to create a database backup. Automated backups run weekly on Sundays at 2:00 AM with 30-day retention.

10. Profile & Security

Updating Profile

Click your name → Profile. Update your name and email.

Changing Password

In Profile, use the Update Password section. Enter current password, new password, and confirm.

Two-Factor Authentication (MFA)

  1. In Profile, click Setup under Two-Factor Authentication
  2. Scan the QR code with Google Authenticator, Authy, or any TOTP app
  3. Enter the 6-digit verification code from your app
  4. Click Enable
  5. On next login, you'll be prompted for the code after entering your password

Password Recovery

  1. On the login page, click Forgot your password?
  2. Enter your email address
  3. Check your email for a reset link
  4. Click the link and set a new password

11. Backup & Maintenance

  • Manual Backup: Settings → Backup Now (one-click database backup)
  • Automated Backup: Runs every Sunday at 2:00 AM (database) and 2:30 AM (files)
  • Retention: Backups kept for 30 days, cleaned automatically
  • Location: storage/app/QueenBuilders-IMS/
